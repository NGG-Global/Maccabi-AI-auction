# Copy glossary

Plain, clear Hebrew. Plural address ("אתם") avoids gendered forms. No emoji anywhere. The repo strings on the left were taken from the code at commit `151e3a1`. Search for each one, because the exact wording may differ slightly.

## Banned terms (must not appear in the UI)
| Banned | Use instead |
|---|---|
| מכת פטיש | סגירת הסבב |
| להרים שלט / הרימו שלט / השלט שלך הורם | שליחת הצעה / שלחו / ההצעה נשלחה |
| שלט N (participant numbers) | the participant's name, with a ParticipantMark showing the first letter |
| חדר / חדרים (in staff UI copy) | סשן / סשנים. The code and the DB keep "room". |

**"היגד" or "פריט"?** The design uses "פריט" in the sale context (lots), on the phone and the projector. If the facilitators prefer "היגד" for leadership rooms, keep one term per surface and ask Dor before mixing them.
