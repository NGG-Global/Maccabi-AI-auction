# ערכת הטמעה: עיצוב "משחק קופסה"

הערכה הזו מיועדת ל־Claude Code. היא מחליפה את העיצוב של הריפו `NGG-Global/Maccabi-AI-auction` בעיצוב "משחק קופסה מודרני", ושומרת על כל הלוגיקה של המשחק כמו שהיא. היא מחליפה את הערכה הקודמת של "ערב מכירה", שאסור להשתמש בה.

## איך משתמשים

1. מחלצים את הזיפ לתיקייה בשם `design-kit/` בשורש הריפו. אם נשארה שם הערכה הקודמת, מוחקים אותה קודם.
2. פותחים את Claude Code בתיקיית הריפו.
3. מעתיקים את כל התוכן של `CLAUDE_CODE_PROMPT.md` ומדביקים אותו כהודעה הראשונה.
4. Claude Code יעבוד בענף `redesign/board-game`, שלב אחרי שלב, ויעצור לאישור אחרי כל שלב.

## מה יש בערכה

| קובץ | תפקיד |
|---|---|
| `CLAUDE_CODE_PROMPT.md` | ההנחיה להדבקה ב־Claude Code |
| `IMPLEMENTATION_PLAN.md` | מיפוי של כל קובץ בריפו למסך שלו, השלבים, מה אסור לשנות, ותנאי קבלה |
| `DESIGN.md` | מערכת העיצוב: צבעים, גופן Fredoka, צללים קשיחים, מידות ותנועה |
| `COMPONENTS.md` | מפרט לכל רכיב, כולל מצבים והתנהגות |
| `COPY.md` | מילון הקופי: מה מחליפים במה |
| `PRODUCT.md` | הקשר המוצר |
| `tokens/theme.css` | טוקנים, רקע מנוקד, מחלקת "כלי משחק" ואנימציות, מוכנים להדבקה ב־`app/globals.css` |
| `reference/prototype.html` | האב־טיפוס החי. פותחים בדפדפן כדי לראות את ההתנהגות |
| `reference/directions-comparison.html` | לוח ההשוואה שממנו נבחר הכיוון |
| `reference/screenshots/` | 16 צילומי מסך של כל המסכים והמצבים |

## לפני שמתחילים

- **שינויים בבסיס הנתונים (שלב 6):** יחידת תקציב (₪ או מטבעות) וקפיצה בכל לחיצה דורשות מיגרציה. Claude Code הונחה לא לבצע אותן בלי אישור שלך.
- **"פריט" או "היגד":** בעיצוב כתוב "פריט". אם רוצים "היגד", צריך לעדכן את `COPY.md` לפני שמתחילים.
- **שמות במסכים:** כל השמות בצילומים ובאב־טיפוס מדומים. אין בערכה מידע פנימי של NGG או של לקוחות.
