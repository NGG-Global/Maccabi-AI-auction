# ערכת הטמעה: ערב מכירה

הערכה הזו מיועדת ל־Claude Code. היא מחליפה את העיצוב של הריפו `NGG-Global/Maccabi-AI-auction` בעיצוב "ערב מכירה" שאושר באב־טיפוס, ושומרת על כל הלוגיקה של המשחק כמו שהיא.

## איך משתמשים

1. מחלצים את הזיפ לתיקייה בשם `design-kit/` בשורש הריפו.
2. פותחים את Claude Code בתיקיית הריפו.
3. מעתיקים את כל התוכן של `CLAUDE_CODE_PROMPT.md` ומדביקים אותו כהודעה הראשונה.
4. Claude Code יעבוד בענף נפרד, שלב אחרי שלב, ויעצור לאישור אחרי כל שלב.

## מה יש בערכה

| קובץ | תפקיד |
|---|---|
| `CLAUDE_CODE_PROMPT.md` | ההנחיה להדבקה ב־Claude Code |
| `IMPLEMENTATION_PLAN.md` | מיפוי של כל קובץ בריפו למסך שלו, השלבים, מה אסור לשנות, ותנאי קבלה |
| `DESIGN.md` | מערכת העיצוב: צבעים, טיפוגרפיה, ריווח, תנועה וכללים |
| `COMPONENTS.md` | מפרט לכל רכיב חדש, כולל התנהגות ומצבים |
| `COPY.md` | מילון הקופי: מה מחליפים במה |
| `PRODUCT.md` | הקשר המוצר, לסקיל impeccable אם משתמשים בו ב־Claude Code |
| `tokens/theme.css` | טוקנים ואנימציות שמוכנים להדבקה ב־`app/globals.css` |
| `reference/prototype.html` | האב־טיפוס החי. פותחים בדפדפן כדי לראות את ההתנהגות |
| `reference/screenshots/` | 16 צילומי מסך של כל המסכים והמצבים |

## לפני שמתחילים

- **שינויים בבסיס הנתונים (שלב 6):** יחידת תקציב (₪ או מטבעות) וקפיצה בכל לחיצה דורשות מיגרציה. Claude Code הונחה לא לבצע אותן בלי אישור שלך.
- **שמות במסכים:** כל השמות בצילומים ובאב־טיפוס מדומים. אין בערכה מידע פנימי של NGG או של לקוחות.
- **דחיפה ו־PR:** Claude Code לא ידחוף ל־main. ההנחיה מבקשת ענף נפרד, ואת ה־PR פותחים אחרי שאתה עובר על התוצאה.
